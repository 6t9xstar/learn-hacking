# Changelog

All notable changes to this repository are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-31

### Added

- Complete repository structure, MIT License, project mission, ethics guidance, and legal disclaimers.
- Six foundation guides: networking, Linux, Windows, programming, cybersecurity fundamentals, and security ethics.
- Ten major specialization guides: ethical hacking, network penetration testing, web application security, mobile security, wireless security, cloud security, digital forensics, malware analysis, SOC/blue team, and red team.
- Sixteen additional-topic directories covering bug bounty, Active Directory and Windows Server security, Linux security, cryptography, OSINT, IoT, hardware, blockchain and smart contracts, AI/LLM security, DevSecOps, application security and secure development, exploit development, threat intelligence, security architecture, GRC, and career development.
- Twelve role-based learning roadmaps with free resources, labs, milestones, portfolio projects, certifications, and exit criteria.
- Curated resource library with free courses, training grounds, open-source tools, official documentation, books, certifications, CTFs, communities, and machine-readable metadata.
- Twelve practical projects with setup, tasks, expected results, deliverables, troubleshooting, and portfolio guidance.
- Four drill workbooks, five operational checklists, four professional report templates, and a cybersecurity glossary.
- GitHub issue templates, pull request template, contribution guide, code of conduct, security policy, and support policy.
- Automated Markdown linting, internal link and anchor validation, external link checking, structure validation, and spell checking.
- Repository banner and navigation system.

### Security

- Established explicit authorized-lab boundaries for all offensive material.
- Added malware, forensics, cloud, wireless, and home-lab safety controls.
- Added a private vulnerability reporting process and content-safety review policy.

### Known limitations

- External resources change frequently; automated checks cannot validate educational quality.
- Some labs require paid platform tiers for full access; free portions are labelled.
- Content is English-first. Community translations are planned.
- Legal summaries are educational and jurisdiction-specific; they are not legal advice.
