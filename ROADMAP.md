# Repository Roadmap

This is the maintenance and content roadmap for the repository itself. For personal learning paths, start with the [learning roadmaps](roadmaps/README.md).

## Current status

Version **1.0.0** establishes the full curriculum map:

- six foundation tracks;
- ten major cybersecurity specializations;
- sixteen additional-topic directories covering nineteen requested subjects;
- twelve role-based learning roadmaps;
- a curated, machine-readable resource catalog;
- twelve practical projects;
- drills, checklists, report templates, and a glossary;
- link, structure, Markdown, and spelling automation.

## Guiding principles

1. **Free first.** Recommend paid material only when it adds unique value and label it clearly.
2. **Practice over bookmarks.** Every path should lead to evidence of learning.
3. **Safe by default.** Offensive material stays within explicit authorized-lab boundaries.
4. **Primary sources.** Cite official documentation and standards.
5. **Maintainable.** Small, verifiable resources with owner and review dates beat link dumps.
6. **Accessible.** Explain acronyms, avoid gatekeeping, support low-resource learners.

## Near-term priorities (next 90 days)

- [ ] Manually review every external link and cost label after the initial automated pass.
- [ ] Add three solved, sanitized sample reports so learners can see expected quality.
- [ ] Add a beginner-friendly lab setup video script or text walkthrough with screenshots.
- [ ] Expand cloud labs for Azure and Google Cloud alongside AWS.
- [ ] Add translated summaries for the README and learning guide, beginning with the most requested languages.
- [ ] Add an automated check that compares `resources/data/resources.json` with links in resource pages.
- [ ] Add contributor office-hours or discussion cadence if demand exists.

## Medium-term priorities (3-9 months)

- [ ] Add a structured Windows/Active Directory lab build with licensing-safe evaluation steps.
- [ ] Add a malware analysis sample workbook using only benign or purpose-built training artifacts.
- [ ] Add detection engineering exercises with reproducible synthetic telemetry.
- [ ] Add a mobile lab track for both Android and iOS, respecting platform restrictions.
- [ ] Add accessibility review for tables, diagrams, and link text.
- [ ] Build a simple static catalog view generated from the resource JSON.
- [ ] Establish a quarterly resource review rotation and publish review notes.

## Long-term ideas

- [ ] Community-reviewed translations for all major guides.
- [ ] Instructor toolkit with lesson plans for classrooms and study groups.
- [ ] Regional legal and certification notes, reviewed by qualified local contributors.
- [ ] Offline-friendly release bundles for low-bandwidth learners.
- [ ] Integration with open courseware and university security programs.
- [ ] A public changelog of resource removals and why they were removed.

## Non-goals

- Hosting live attack infrastructure or providing a hacking service.
- Publishing zero-days, malware samples, credential dumps, or exam answers.
- Ranking learners by streak, rank, or number of tools collected.
- Replacing formal legal, compliance, or incident-response advice.
- Chasing every new tool at the expense of durable fundamentals.

## How to propose a roadmap change

Open an issue using the feature-request template and include:

- the learner problem you are solving;
- evidence of demand;
- what already exists and why it is insufficient;
- the proposed change and maintenance plan;
- any safety, legal, or accessibility implications.

## Release cadence

Content updates are continuous. Minor releases are tagged when a coherent set of guides, labs, or automation changes lands. Security and safety fixes are prioritized and may ship immediately.
